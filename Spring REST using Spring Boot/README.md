## 📖 About

This repository contains hands-on exercises for learning **Spring REST** using **Spring Boot**. The exercises focus on building RESTful web services, creating Spring Boot applications, handling HTTP requests and responses, configuring Spring applications, and implementing **JWT (JSON Web Token)** based authentication.

These practical exercises are part of the **Cognizant Digital Nurture (DN) Program**, providing real-world experience in developing enterprise-grade REST APIs with Spring Boot.

---

## 🎯 Repository Objectives

- Understand RESTful Web Services using Spring Boot.
- Develop REST APIs following REST principles.
- Configure Spring applications using XML.
- Handle HTTP requests and responses.
- Retrieve resources using REST endpoints.
- Implement JWT-based authentication.
- Build scalable backend services using Spring Boot.

## ⚙️ Prerequisites

Before running the project, ensure the following are installed:

- Java JDK 17 or above
- Apache Maven
- Git
- Eclipse IDE / IntelliJ IDEA / VS Code
- Postman (for testing REST APIs)

---

## ▶️ How to Run

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project

```bash
cd "Spring REST using Spring Boot"
```

### Build the Project

```bash
mvn clean install
```

### Run the Application

```bash
mvn spring-boot:run
```

Or run the main Spring Boot application class from your IDE.

## 🧪 Testing REST APIs

The REST endpoints can be tested using:
