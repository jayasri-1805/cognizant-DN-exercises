## 📖 About

This repository contains hands-on implementations demonstrating the fundamentals of **JUnit 5**, **Mockito**, and **SLF4J**. The exercises focus on unit testing, assertions, mocking, interaction verification, and logging practices commonly used in Java applications.

These hands-on exercises help in understanding test-driven development concepts and writing reliable, maintainable, and scalable Java applications.

---

## 🎯 Repository Objectives

- Learn unit testing using JUnit 5.
- Understand assertions and testing best practices.
- Apply the Arrange-Act-Assert (AAA) testing pattern.
- Create mock objects using Mockito.
- Verify interactions between dependent objects.
- Implement logging using the SLF4J framework.
- Improve software quality through automated testing.

## ▶️ How to Run

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project

```bash
cd "JUnit, Mockito and SLF4J"
```

### Build the Project

```bash
mvn clean install
```

### Run the Test Cases

```bash
mvn test
```
