# JUnit, Mockito and SLF4J - Mandatory Hands-on

## Overview

This repository contains hands-on exercises demonstrating the fundamentals of **JUnit 5**, **Mockito**, and **SLF4J**. These exercises cover unit testing, assertions, mocking, interaction verification, and logging practices commonly used in Java applications.

---

## Technologies Used

- Java 8
- Maven
- JUnit 5
- Mockito
- SLF4J
- Eclipse / IntelliJ IDEA / VS Code

## Exercises

### JUnit Basic Testing Exercises

### Exercise 1 – Setting Up JUnit

**Objective**
- Configure JUnit in a Maven project.
- Write and execute a simple unit test.

**Concepts Covered**
- JUnit dependencies
- Test annotations
- Running test cases

---

### Exercise 3 – Assertions in JUnit

**Objective**
- Learn different assertion methods available in JUnit.

**Concepts Covered**
- assertEquals()
- assertTrue()
- assertFalse()
- assertNull()
- assertNotNull()
- assertThrows()

---

### Exercise 4 – Arrange-Act-Assert (AAA) Pattern

**Objective**
- Write clean and maintainable unit tests using the AAA testing pattern.

**Concepts Covered**
- Arrange
- Act
- Assert
- Test readability

---

## Mockito Exercises

### Exercise 1 – Mocking and Stubbing

**Objective**
- Create mock objects.
- Stub method behavior.

**Concepts Covered**
- Mockito.mock()
- when().thenReturn()
- Dependency isolation

---

### Exercise 2 – Verifying Interactions

**Objective**
- Verify interactions between objects.

**Concepts Covered**
- verify()
- times()
- never()
- Interaction testing

## How to Run

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the project

```bash
cd "JUnit, Mockito and SLF4J"
```

### Run Maven Tests

```bash
mvn test
```

After completing these exercises, you will be able to:

- Write unit tests using JUnit 5.
- Use assertions effectively.

- Verify method interactions.
