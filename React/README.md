## 📖 About

This repository contains hands-on exercises for learning **ReactJS**, covering the fundamentals of modern frontend development. The exercises demonstrate component-based architecture, JSX, props, state management, event handling, forms, conditional rendering, lists, styling, and the development of complete React applications.

These exercises are part of the **Cognizant Digital Nurture (DN) Program**, providing practical experience in building interactive and responsive web applications using React.

---

## 🎯 Repository Objectives

- Understand the fundamentals of ReactJS.
- Learn component-based application development.
- Build reusable React components.
- Manage application state using Hooks.
- Handle events and forms in React.
- Apply conditional rendering and list rendering.
- Style React applications using CSS Modules and inline styling.
- Develop complete React applications using best practices.

## ▶️ How to Run

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Required Exercise

```bash
cd React/Mandatory\ Hands-on/<exercise-folder>
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm start
```

or (for Vite-based projects)

```bash
npm run dev
```

The application will open in your browser at:

```
http://localhost:3000
```

or

```
http://localhost:5173
```

depending on the project configuration.
