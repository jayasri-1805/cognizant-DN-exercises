## 📖 About

This repository contains the implementation of **Data Structures and Algorithms** laboratory exercises developed in Java. Each exercise is based on a real-world scenario and demonstrates the practical application of fundamental data structures, algorithms, and complexity analysis.

The repository focuses on developing problem-solving skills through efficient algorithm design and appropriate data structure selection.

---

## 🎯 Repository Objectives

- Understand fundamental data structures and algorithms.
- Implement real-world problem-solving applications.
- Analyze time and space complexity.
- Compare different algorithms based on performance.
- Improve programming and analytical skills.

# 📚 Exercises

## 📌 Exercise 1 – Inventory Management System

### Concepts Covered
- Data Structures
- ArrayList
- HashMap
- CRUD Operations
- Time Complexity Analysis

### Scenario
Develop an inventory management system that efficiently stores and manages product details.
