## 📖 About

This repository contains hands-on exercises for learning **Spring Data JPA**, **Hibernate**, and **Spring Boot**. The exercises demonstrate Object Relational Mapping (ORM), entity mapping, repository interfaces, CRUD operations, database connectivity, and enterprise application development using the Spring ecosystem.

The repository is part of the **Cognizant Digital Nurture (DN) Program**, providing practical experience with database-driven Spring Boot applications.

---

## 🎯 Repository Objectives

- Understand Object Relational Mapping (ORM).
- Learn Hibernate fundamentals.
- Explore Spring Data JPA architecture.
- Implement CRUD operations using Repository interfaces.
- Configure database connectivity.
- Build Spring Boot database applications.
- Compare Hibernate and Spring Data JPA.

## ▶️ How to Run

### Clone the Repository

```bash
git clone <repository-url>
```

### Navigate to the Project

```bash
cd "Spring Data JPA with Spring Boot & Hibernate"
```

### Build the Project

```bash
mvn clean install
```

### Run the Application

```bash
mvn spring-boot:run
```

Or run the Spring Boot main class directly from your IDE.
